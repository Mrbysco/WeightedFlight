# Weighted Flight #

## About ##
Weighted Flight causes Elytra flight to become slower the more armor you're wearing. The better the armor you're wearing the slower / shorter the elytra flight will become.

A player wearing an Elytra and leather gear will fly further than a player wearing Diamond or Netherite.

The following options can be configured in the config:
* **armorPieceShare** - How much the number of armor pieces matters compared to their armor value (0 = value only, 1 = pieces only)
* **toughnessShare** - How much armor toughness matters compared to armor value, makes Netherite heavier than Diamond
* **maxElytraSlowdown** - Maximum slowdown per tick for a fully armored player (0 to disable)
* **armorWeightCurve** - How quickly the slowdown ramps up (1 = linear, higher = light armor barely matters)
